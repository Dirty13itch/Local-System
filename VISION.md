## Core Principles

### 1. Sovereignty
No corporation decides what this system can think about, remember, or do. No API terms of service constrain its capabilities. No cloud provider can revoke access. The hardware is owned. The data stays local. The models are uncensored. The system answers to one person.

### 2. Autonomy with Alignment
The system operates independently but remains aligned with the operator's goals. It doesn't ask permission for routine operations. It escalates only when genuinely uncertain or when actions are irreversible.

```

                       deployment             spending             permission

                       changes                integrations

                       (with rollback plan)
```

### 3. Persistence
Cloud AI has no memory between sessions. This system accumulates knowledge, context, and capability over months and years of continuous operation. Every conversation, every project, every discovery becomes part of its growing understanding.

### 4. Right Over Fast
Quality and correctness matter more than speed. Plan before executing. Validate after changes. Roll back on failure. Document decisions and rationale.

### 5. Continuous Improvement (改善)
The system gets better over time through fine-tuning, memory consolidation, architecture evolution, and learned understanding of its operator.
