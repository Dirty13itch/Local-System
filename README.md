# Local-System — Sovereign AI Platform

> A sovereign local AI platform running on privately owned hardware — persistent memory, autonomous agents, and deep personalization for a single human operator.

## Quick Start

```bash
# 1. Set up DEV node (run on fresh Ubuntu)
bash scripts/setup-dev.sh

# 2. Or clone and configure manually
git clone https://github.com/Dirty13itch/Local-System.git && cd Local-System
cp .env.example .env
# Edit .env with node IPs from docs/infrastructure-report.md

# 3. Install shared library
pip install -e shared/python/

# 4. Deploy services
make deploy NODE=vault       # Databases, orchestration, gateway
make deploy NODE=foundry     # vLLM inference
make deploy NODE=workshop    # vLLM fast, ComfyUI

# 5. Verify
make health                  # Check all nodes
```
